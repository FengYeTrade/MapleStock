# 🍁 枫叶炒股 MapleStock

一款模拟炒股对战平台：10 只 A 股实时模拟行情、K 线走势、真实交易规则、**定时庄家砸盘**，支持多用户注册对战与富豪排行榜。

> 纯模拟资金，无真实交易、无真实资金。适合朋友间娱乐、教学演示。

## ✨ 功能

- 📈 **实时行情**：10 只热门股票（茅台、宁德、比亚迪等）随机波动，SSE 秒级推送
- 📊 **K 线图**：ECharts 蜡烛图 + 成交量，支持 1/2/3 月/全部区间切换
- 💹 **模拟交易**：买入会小幅拉升股价，卖出按现价结算，持仓成本自动摊薄
- ⏱ **庄家砸盘**：每 60 秒倒计时，到期全市场暴跌 99%，所有玩家资产归零（刺激版"牛市熊市"）
- 👥 **多用户系统**：注册/登录（含算术验证码）、每人初始 ¥900,000、账户重置
- 🏆 **富豪排行榜**：按总资产实时 TOP10
- 🕵️ **庄家后台**：查看/迁入/删除用户、手动砸盘、一键重置（口令默认 `admin888`，见下方安全说明）

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
python app.py

# 3. 浏览器打开
#    http://localhost:5050
```

首次启动自动创建 SQLite 数据库 `stock.db` 并生成 200 天历史 K 线。

## 🔒 安全说明

- **庄家口令**：后端内置后门口令默认 `admin888`，**上线前务必修改**：
  ```bash
  export MAPLESTOCK_ADMIN_PASS='你的强口令'
  python app.py
  ```
- 密码使用 SHA-256 存储（演示用途），请勿用于真实系统。
- 本项目仅用于学习与娱乐演示。

## 📁 目录结构

```
MapleStock/
├── app.py               # Flask 后端（行情引擎 / 交易 / 用户 / SSE / 排行榜）
├── templates/
│   └── index.html       # 前端单页应用（行情 / 交易 / 持仓 / 排行）
├── static/              # 静态资源（预留）
├── requirements.txt     # Python 依赖
├── stock.db             # SQLite 数据库（首次启动自动生成，不入库）
└── .gitignore
```

## 🛠 技术栈

- 后端：Python 3 + Flask + SQLite + SSE
- 前端：原生 HTML/CSS/JS + ECharts 5.5（CDN）
- 实时：EventSource 服务端推送
